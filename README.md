# Happy 18th Monthsary 🌷

A pink 3D tulip bouquet (18 tulips, one for each month) with a love letter and our photos,
built with React + three.js ([React Three Fiber](https://r3f.docs.pmnd.rs)).

## Run it

```sh
npm install   # first time only
npm run dev   # then open http://localhost:5173
```

To try it on a phone, open the **Network** link Vite prints (phone on the same Wi-Fi).

- Tap the envelope ("open me") to open the letter
- Tap a tulip for a burst of hearts
- Tap a polaroid to see the photo big (arrows / swipe to flip through)
- Drag to look around, pinch or scroll to zoom

## Change the words or photos

Everything written on the page is in [`src/message.js`](src/message.js): the title, the letter
paragraphs, the envelope label, and the list of photos (the files are in `public/photos/`).

## Share it

`npm run build` creates `dist/`, a static site you can upload to Netlify, Vercel, GitHub Pages
and similar. Anyone with the link can see the photos, so share the link privately.

## The 3D model

`public/models/bouquet.glb` is generated by [`blender/build_bouquet.py`](blender/build_bouquet.py)
(Blender 5.2). To change colours or shapes, edit the script and run it in Blender's Text Editor;
it rebuilds the "Bouquet" collection and re-exports the `.glb`. `blender/bouquet.blend` is a saved
copy of the scene.

## Where things are

| File | What it does |
| --- | --- |
| `src/components/Bouquet.jsx` | Loads the model; tulip taps and the envelope opening |
| `src/components/Polaroids.jsx` | The photo frames around the bouquet |
| `src/components/LetterOverlay.jsx` | The letter you read after opening the envelope |
| `src/components/Lightbox.jsx` | Full-size photo viewer |
| `src/components/FallingPetals.jsx`, `HeartBurst.jsx` | Petals and hearts |
| `src/styles.css` | Pink theme, fonts, letter styling |
